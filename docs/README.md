# Producto — Angeli Asistente

Esta carpeta contiene la planificación funcional de Angeli. No sustituye `PROJECT_MEMORY.md`: la memoria conserva decisiones técnicas e históricas; estos documentos describen hacia dónde debe evolucionar la experiencia de la persona usuaria.

## Documentos

- [Visión de producto](PRODUCT_VISION.md): propósito, principios y límites de Angeli.
- [Roadmap](ROADMAP.md): bloques de evolución, orden y dependencias.
- [Acciones programadas](specs/01-scheduled-actions.md): especificación del primer bloque que se va a construir.

## Regla de trabajo

Antes de comenzar una funcionalidad del roadmap, convertir su especificación en una tarea acotada: objetivo, datos afectados, integraciones, seguridad, pruebas locales y pruebas manuales Android. Ninguna fase se considera estable hasta completar sus pruebas reales.
